Design notes

Why this layout

  • Left navigation in the order you work: start → build → people & time → check. Same pattern as Azure DevOps settings pages.
  • Grid editor split into tabs (Overview, Columns, Dates & effort, Review, Presets, Totals, Child items) instead of one long page. The Overview tab shows the state of each part and what needs attention.
  • Master and detail: a list on the left, the selected item on the right, for grids, calculations, presets and lists.
  • One save bar at the top with the live error / warning count, always visible.
  • Every warning has a Fix button that jumps to the right place.

Where today's tabs go

  • Rules + Dependent dropdowns → Rules & dropdowns (two tabs)
  • Grids → Grids (seven tabs)
  • Mappings → Shared lists
  • Calculations → Calculations
  • Capacity → Capacity & calendar (source, people, overview)
  • Read-only fields + JSON + validation list → Health check

Not changed

  • Logic, saved configuration and the work item controls stay exactly as they are. Only the setup screens are regrouped.
