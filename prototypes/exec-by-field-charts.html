By-field chart: auto-chosen type with an override

Pick a field in the drop-down. Auto chooses Columns (≤ 6 values), Bars (≤ 12) or a ranked Table (more), or Columns in natural order for ordered fields. The Bars / Columns / Pie / Table switch overrides it. Pie is never chosen by Auto (it shows share, not status); it uses neutral burgundy and grey slices so the status colours keep their meaning, and merges values beyond 8 into “Other”. The card keeps a fixed height, so the columns around it never move. Try the Project manager field (44 values).

Click a bar, column or table row to filter the dashboard (a chip appears, as today).
