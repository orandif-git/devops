By-field chart: auto-chosen type with an override

Pick a field in the drop-down. Auto chooses Columns (≤ 6 values), Bars (≤ 12) or a ranked Table (more), or Columns in natural order for ordered fields. The Bars / Columns / Table switch overrides it. The card keeps a fixed height, so the columns around it never move. Try the Project manager field (44 values).

Click a bar, column or table row to filter the dashboard (a chip appears, as today).
